# 提示词任务分类

本轮实现范围是源代码与本地回归，不包含提交、发布、安装或日用版替换。

## 分类与查找

- 每条提示词只有一个主要任务分类；工具、方法作为细分标签。AI 优先复用已有目录，真正不同的任务才建议新分类。
- 新建先保存完整正文，再异步分类。已有类直接归入；新类保留为建议，用户查看收录边界、可修改名称，确认后加入目录。用途不明确或服务失败保留在待分类，可重试。
- 目录从已确认提示词的分类派生，没有固定预置清单；当某类已没有条目时，该分类不再显示。禁止“其他、通用、优化”等含糊或保留类名。
- 历史提示词通过“AI 分类整理”分批分析，先预览每条归属、理由及分类边界，可修改归属；应用时才写入并确认新目录。取消保留已完成建议，返回不写资料。人工分类跳过，失败或内容已更改的条目不覆盖。
- 分类、搜索和细分标签取交集；标签在当前分类内选择，标签之间匹配任一。无结果可“搜索全部”。常显最多五个任务分类，其余由“更多分类”查找，长名称不换行挤占正文。
- 单击查看，方向键选择，复制按钮或 Enter 复制；沿用原有复制次数、排序、分批追加和虚拟化。

## AI 调用和失败

复用 AI 整理设置的地址、认证、代理、传输校验和有界响应读取。自动整理开关仅控制新建时是否同时整理标题、描述和标签，分类仍会触发；没有配置模型时显示设置提示并保留正文。分类请求也会整理细分标签。

一批最多十条，序列化后的正文、元数据与目录合计最多 60,000 字符；超限在发出请求前拒绝，不截断正文。批量顺序请求，后续批复用前批候选目录；单批分类请求有 5 分钟截止时间，底层 HTTP 客户端上限同步为 5 分钟，仍可主动取消。元数据整理与分类合为一次请求。模型目录获取仍有独立的 30 秒截止时间，旧的独立元数据整理接口仍为 20 秒。

待分类正文作为数据发送，系统提示明确禁止执行其中指令。返回结果检查分类登记、原始 ID 完整且唯一、字段类型和长度；无效结果不写入。AI 不改正文；写入前重新读取并检查内容与更新时间，拒绝迟到覆盖或删除后复活。复制次数变化不阻止分类，也不会丢失次数。写入后台执行，退出等待已经排队的写入。

## 数据与同步

本地 `library.json` 仍为 schema 1，增量保存 Category、CategoryDescription、CategoryManual、SuggestedCategory、SuggestedCategoryDescription、CategoryNote；旧资料缺少这些字段时默认待分类，无数据库 migration，也没有迁移个人资料。编辑、克隆、冲突比较及同步均保留分类字段。

资料库同步协议从 2 升至 3，拒绝混用旧协议，避免旧设备忽略分类后回传造成字段丢失。**两台设备均需支持分类的新版才能继续同步提示词与模型资料**；此限制不代表剪贴板、文件通道协议变化。未替换日用版，未执行真实双机验证。旧程序直接打开并保存新资料文件仍可能丢弃未知字段，不支持这种降级写入。

## 验证入口与边界

核心回归：`PromptClassificationTests`、`LibraryStoreTests`、`LibrarySyncTests`、`LibrarySyncOptimizationTests`、`LibraryHttpTests`、`LibraryFilterPerformanceTests`、`PromptCopyConcurrencyTests`、`FloatFolderImporterTests`。合计 104 项通过，覆盖新类确认、空白或模糊名称拒绝、重启与合并、人工分类保护、迟到结果、复制并发、筛选交集、超长输入拒发、完整正文发送及旧协议拒绝。

WPF 入口 `ProductShellStartsWithCaptureAndKeepsAllDestinationsReachable` 使用以下环境变量分别运行：

- `SCREEN_TRANSLATE_PROMPT_CATEGORIES_ONLY=1`：分类与更多目录、搜索范围、单击预览、新建自动分类、元数据开关、新类审阅及确认、失败保留、批量应用、浅深主题。
- `SCREEN_TRANSLATE_SAVE_FEEDBACK_ONLY=1`：保存、并发、失败与取消反馈。
- `SCREEN_TRANSLATE_REFRESH_AUDIT_ONLY=1`：快照刷新、搜索隔离、紧凑布局与复制。
- `SCREEN_TRANSLATE_FRONTEND_PERFORMANCE_ONLY=1`：后台读取与请求合并。
- `SCREEN_TRANSLATE_LIBRARY_REGRESSION_ONLY=1`：原有资料库、编辑及 AI 设置入口。
- `SCREEN_TRANSLATE_COPY_SYNC_ONLY=1`：复制次数与合成同步刷新。

上述六组 WPF 专项均在最终相关改动后各通过一个入口，零失败、零跳过。原有排版与单击复制夹具已按描述优先、单击查看的已确认行为同步；保留并按实际条目尺寸验证默认至少七行、最小至少四行的密度要求。长标题、十二标签及快捷设置场景下，最小正文视口实测 76 DIP。

独立 Impeccable 复核发现并确认解决三项问题：最小窗口确认入口隐藏、正文被挤压、列表密度回退；修复项复核结论为 `ship`，只覆盖这三项及提交的离屏证据。源码与离线回归交付状态为 `PASS_WITH_RISKS`，风险为下述真实环境验证缺口。

这些测试使用临时资料、模拟 HTTP 和注入的复制操作。截图来自实际 WPF 控件的离屏渲染；不等于日用版、真实 Provider、双机、辅助技术或不同 DPI 的端到端验收。AI 分类语义是否符合个人资料仍需真实模型与代表性提示词验证，不能用模拟接口通过代替准确率结论。
