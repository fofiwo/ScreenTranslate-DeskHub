# 桌面视觉改造对抗性复核 · 2026-11-11

## 范围与判定依据

使用 Impeccable 的 audit/native、craft-floor 和 delivery-review，检查 Fluent 分层改造的实际 WPF 控件、共享样式、长内容、浅深主题、DPI 和直接消费者。原生参考中的触屏规则不机械套用于 WPF。

视觉改造的基线是 `artifacts/visual-refresh-20261111/source-before/` 中的 18 个 XAML 快照；Git HEAD 同时包含其他任务的起点，不能据此把整个工作区归因于视觉改造。原有文件接收、分块取消、收件归档、快捷预加载及截图 STA 改动保留，并在提交前纳入完整核心及 UI 工程测试。

## 发现与处置

| 发现 | 触发、证据与归因 | 处置 |
| --- | --- | --- |
| 长标题使消息正文侵入操作区 | 160 字标题、4000 字正文，浅深主题、100%/200% DPI；正文视口下边缘 730 DIP，按钮区起点 580 DIP。`before.trx` 保留失败。新布局没有正确约束标题和正文的总高度。 | 固定底部操作区；标题和正文共用受约束的 ScrollViewer，移除嵌套正文滚动。正文末尾可达，默认按钮、关闭和取消语义不变。 |
| 输入和未选中复选框边界偏淡 | `#B8C5DC` 对白底 1.74:1，对分组底 1.55:1，低于 3:1；为既有问题，本轮保留后暴露于复核。 | 曾尝试加深，但用户明确要求保留原浅色，已恢复。对比度缺口作为已知保留项，不宣称无障碍审计通过；对应强制深色阈值断言已移除，保留弹窗行为回归。 |
| 主任务黄色不符合用户最终偏好 | 视觉初稿使用浅黄 `#FFF1CC`。 | 按最终要求恢复亮橙黄 `#FFBE24`；标题/说明对比度为 9.17:1 / 5.99:1，同步 DESIGN 和视觉说明。 |
| 全量 UI 的外部剪贴板占用夹具失败 | 首轮 2 项中 1 通过、1 失败，`External clipboard fixture did not acquire the lock`，`ui-full.trx`。独立探针随后成功，尚不能证明首轮的确切原因。 | 夹具改为最多 3 秒重试取锁，并补充子进程错误诊断；保持真实占用断言、复制次数和文本校验，不跳过测试或修改产品重试逻辑。最终结果见下表。 |
| 公开快照遗漏设计和复核文档 | 既有 exporter 只导出指定文档，新增设计及专项报告不在 allowlist。 | 加入明确的文档白名单；继续排除个人数据、凭据、构建产物及开发历史。 |

新回归测试最初出现同名辅助方法编译错误和默认结果断言误读，均已更正测试本身：YesNoCancel 的初始关闭结果应为 Cancel，默认高亮按钮可以为 No，未据此改动产品取消行为。

证据在 `artifacts/visual-adversarial-20261111/`，最终截图来自真实 WPF 控件树，不是网页重绘。渲染结果不能证明物理设备、线上服务或所有可访问性场景。夹具争用探针没有稳定复现首轮失败，不将该实验当作已确认根因证据；重试和诊断属于测试夹具加固。

## 全部已知剩余问题与未验证项

1. 原浅色控件边界保留上述对比度缺口；未完成高对比度系统主题、读屏、色觉障碍和全应用文字/图形对比度审计。Impeccable 的旧 surface 元数据仍描述早期设计，未将元数据升级扩大成本次任务；最终视觉以代码、DESIGN 及本文为准。
2. 未在真实多显示器/混合 DPI、低性能电脑、休眠恢复、长时闲置、真实物理键鼠、触摸及 IME 环境全面验收；离屏 100%/200% 不能替代这些设备场景。
3. 未进行在线 OCR/翻译 Provider 联调、两台物理电脑同步、防火墙、弱网、断网恢复、锁屏/UAC、独占全屏及系统提示音可听性验收；17 个核心跳过项没有本轮执行证据。
4. 其他电脑首次截图结束后无图的原始问题未稳定复现，不能宣称根因闭环。新版本真实桌面捕获、OLE 持久化、跨进程粘贴、历史落盘与第三方监听争用未完整重验；写后校验不能防止其他程序稍后覆盖剪贴板。
5. 快捷预加载移动初始化时机但不消除工作，会提前占用窗口内存；刚启动、输入队列持续繁忙或准备失败仍可能冷开。生产启动/退出竞态、真实输入到首帧延迟与长期资源增长未完整验证。此前并行测试的间歇失败原因仍未确证。
6. 文件取消需两端新版；旧端、异常、等待超时仍可能断开设备会话，迟到取消可能遇到已完成传输。收件归档无法恢复旧版已淘汰记录；历史目录移动/删除后打开会失败；大量归档加载和长期多设备压力未验证。
7. 未实际等待满 5 分钟、原生目录选择成功的完整人工路径、真实磁盘写满/ACL/杀毒拦截/重解析点与移动并发未完整验证；没有以合成边界断言替代这些真实环境结果。归档为本地 JSONL 文件，不涉及数据库 schema/migration；已有有效收件记录补入、损坏行保留及写入失败可见性由核心回归覆盖。
8. 未安装日常版本、未对新安装包独立首次启动及第二台电脑安装运行验收。提交、推送、CI 和发布是不同状态，不能以推送成功推断已通过 CI 或已发布。

## 限定结论

视觉改造及本地自动回归为 **PASS_WITH_RISKS**：已确认的长内容布局问题已修复，黄色与边界色符合用户最终选择。保留浅色边界的可访问性缺口及一次未完全归因的夹具失败；真实双机、设备场景与在线服务的完整产品验收仍为 **BLOCKED**，未用本地测试替代。
