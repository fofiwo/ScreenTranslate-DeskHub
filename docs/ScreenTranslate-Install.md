# ScreenTranslate 安装与双向同步

适用：DeskHub 安装版，适用于 Windows x64。安装程序不包含开发电脑的剪贴板历史、提示词、模型配置、API Key 或其他用户设置。

## 安装

运行 `ScreenTranslate-win-Setup.exe`。两台电脑均应安装本版。安装版将个人数据保存在安装根目录的 `data` 中，例如 `D:\Software\ScreenTranslate\data`，不放在更新时替换的 `current` 目录内。首次启动会将旧 `%LocalAppData%/ScreenTranslate-data` 原样复制到新目录，保留旧文件；已有的新目录优先，不自动覆盖或混合其他资料。

Velopack 的覆盖安装和卸载会删除整个安装根目录。为保证重装后仍可恢复，应用在 `%UserProfile%/.ScreenTranslate/recovery` 保存按安装位置区分的恢复副本，设置、资料库及剪贴板历史每次成功保存或删除后同步更新；首次迁移也建立完整副本。恢复目录避开 MSIX 宿主对 LocalAppData 的重定向，确保从桌面或 Codex 启动时使用同一位置。重装后新目录不存在时自动恢复，重新选择安装位置时可从上次登记的资料恢复。目录准备失败会停止启动，备份失败会报告保存失败，避免误报成功。`%UserProfile%/.ScreenTranslate/profile.txt` 只登记本机当前资料位置，供重装和本地预览复用。

恢复副本不包含可重新下载的模型资源、日志或诊断包。不要手动删除恢复副本来更新软件；文件加密仍绑定原 Windows 用户，本机制不代替跨电脑同步或独立备份。旧便携版的其他目录不会自动导入。

## 首次同步

首次启动会询问是否同步。选择“是”后，默认启用剪贴板、提示词库和模型库，并进入配对。选择“否”后不再反复询问。日常唯一入口为“主窗口左下角 → 设备与同步”；托盘和剪贴板菜单不再重复提供同步入口。

1. 两台电脑连接同一可信局域网并运行软件。
2. 一台在“本机发起”点击“生成”，再点“复制配对信息”发给另一台。另一台在“连接另一台”填写收到的地址与配对码，点击“连接”。复制内容仅保留设备、版本、地址、配对码和同步范围，不含模型 API Key 的实际值，也不进入本软件剪贴板历史或自动同步。
3. 在等待端确认是自己的电脑。配对后不必另配资料库同步，所选内容自动双向同步。

同步现已统一使用一个设备连接。旧版“资料库独立同步”的监听和后台任务已退役，旧 `library/sync.json` 配置保留但不再加载；提示词、模型资料、同步版本和冲突记录保留。原独立同步用户需在两台电脑的“设备与同步”中重新配对，旧配对码和设备地址不会自动迁入。当前仍需在重启或断线后重新配对。

模型库同步包括 API Key，只应与自己的可信设备配对。传输使用加密连接，接收后由接收电脑的 Windows 用户保护敏感字段。可分别暂停剪贴板和资料库同步。

暂停资料库同步会阻止新发送和排队发送；暂停前已开始的传输可能仍会完成。资料库格式或保存失败会拒绝本次内容并自动重试，不再连带断开剪贴板和文件通道。

剪贴板同步新复制的文本和图片，不迁移已有剪贴板历史或补传离线复制。提示词库和模型库首次合并两端已有资料，随后自动传播新增、修改和删除，同时修改保留冲突副本。资料库约每 3 秒检查一次变化。

复制历史条目后，它会移到所在置顶区/普通区的最前，下次唤起自动定位到该条目。文件传输、剪贴板和资料库使用独立逻辑通道。

关闭同步窗口后连接继续，退出软件则结束连接；当前版本重启或断线后需要重新配对。首次防火墙提示请只允许可信的专用网络。协议为 3，两端必须更新到兼容版本。

## 更新

检查更新以 GitHub 最新正式发布为准。即使本机自行构建的版本号高于线上版本，也能选择同步到 GitHub 正式版；窗口显示当前版本、目标版本和切换说明，点击更新后才下载、校验并安装。相同版本不重复安装；跳过操作只对所选版本生效。

更新窗口的“刷新版本”和主动“检查更新”会重新获取最新清单，可直接跨版本升级。若提示无法连接，请在“设置 → 通用与诊断 → 网络代理”填写可用代理（如 `http://127.0.0.1:10808`），启用并勾选“应用更新”，保存后重试。此示例不是自动启用的默认代理；也可分别勾选翻译、词典、语音、在线 OCR、模型下载、资料库联网和诊断上传。设置仅控制应用内请求，不修改系统代理。

本仓库的安装版启动后及每 30 分钟自动检查 [GitHub 最新版](https://github.com/fofiwo/ScreenTranslate-DeskHub/releases/latest)。主窗口左下角显示新版提示，“关于”和托盘也可主动检查；点击“立即更新”会下载、校验、安装并重启，保留个人数据。早期未启用更新的本地版需先手动安装一次新版，此后无需手动替换。更新源固定为本项目，拒绝其他产品安装包。便携版或开发版请下载正式安装版。不要删除个人数据目录来升级软件。
