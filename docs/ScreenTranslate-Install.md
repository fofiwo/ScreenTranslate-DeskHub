# ScreenTranslate 安装与双向同步

适用：DeskHub 安装版，适用于 Windows x64。安装程序不包含开发电脑的剪贴板历史、提示词、模型配置、API Key 或其他用户设置。

## 安装

运行 `ScreenTranslate-win-Setup.exe`。两台电脑均应安装本版。安装版将个人数据保存在 `%LocalAppData%/ScreenTranslate-data`，升级程序不会清空该目录。旧便携版的数据不会自动导入安装版。

## 首次同步

首次启动会询问是否同步。选择“是”后，默认启用剪贴板、提示词库和模型库，并进入配对。选择“否”后不再反复询问；以后可从剪贴板浮窗或托盘的“局域网同步”开启。

1. 两台电脑连接同一可信局域网并运行软件。
2. 一台显示等待配对的地址与配对码；在另一台填写这两项并点击“连接”。
3. 在等待端确认是自己的电脑。配对后不必另配资料库同步，所选内容自动双向同步。

模型库同步包括 API Key，只应与自己的可信设备配对。传输使用加密连接，接收后由接收电脑的 Windows 用户保护敏感字段。可分别暂停剪贴板和资料库同步。

暂停资料库同步会阻止新发送和排队发送；暂停前已开始的传输可能仍会完成。资料库格式或保存失败会拒绝本次内容并自动重试，不再连带断开剪贴板和文件通道。

剪贴板同步新复制的文本和图片，不迁移已有剪贴板历史或补传离线复制。提示词库和模型库首次合并两端已有资料，随后自动传播新增、修改和删除，同时修改保留冲突副本。资料库约每 3 秒检查一次变化。

复制历史条目后，它会移到所在置顶区/普通区的最前，下次唤起自动定位到该条目。文件传输、剪贴板和资料库使用独立逻辑通道。

关闭同步窗口后连接继续，退出软件则结束连接；当前版本重启或断线后需要重新配对。首次防火墙提示请只允许可信的专用网络。协议为 3，两端必须更新到兼容版本。

## 更新

本仓库的安装版启动后及每 30 分钟自动检查 [GitHub 最新版](https://github.com/fofiwo/ScreenTranslate-DeskHub/releases/latest)。主窗口左下角显示新版提示，“关于”和托盘也可主动检查；点击“立即更新”会下载、校验、安装并重启，保留个人数据。早期未启用更新的本地版需先手动安装一次新版，此后无需手动替换。更新源固定为本项目，拒绝其他产品安装包。便携版或开发版请下载正式安装版。不要删除个人数据目录来升级软件。
