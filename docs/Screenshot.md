# 截图、标注、贴图与取色

截图工具独立于 OCR 和翻译，不启动翻译服务、不上传图片、不自动保存文件。

| 操作 | 默认快捷键 |
| --- | --- |
| 开始截图；再次触发取消 | Ctrl+Alt+Q |
| 贴出剪贴板中的图片 | Ctrl+Alt+I |
| 复制选区与标注并退出 | 双击选区 / Enter / Ctrl+C |
| 将选区与标注贴到桌面 | Ctrl+P |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y |
| 复制鼠标所在位置的色值（默认 HEX，#RRGGBB） | C |
| 切换 HEX / RGB 复制格式 | Shift |
| 取消截图或关闭当前贴图 | Esc |

两个全局快捷键可在设置页修改、关闭和录制，冲突时设置页会提示。

拖动框选后，在“选区”工具中移动区域或拖动四角调整大小。选择矩形、箭头、画笔、文字或马赛克进行标注；颜色和粗细仅在标注时显示。文字点击输入，Enter 确认，Shift+Enter 换行。

双击选区空白处或已有标注即可复制；正在编辑的文字、工具栏及四角调整手柄保留各自操作。复制失败时保留选区和标注。剪贴板忙碌重试期间暂时锁定编辑，仍可取消。复制成功后关闭截图界面。

贴图窗口独立置顶，仅显示无边框图片，默认按原始物理像素尺寸（100%）展示，不自动适配屏幕。支持多张并存、拖动和滚轮缩放；Ctrl+C 复制，Esc 或右键菜单关闭。双击贴图或右键菜单可恢复 100%；DPI 变化后保持当前物理像素缩放比例；超大图片可延伸到屏幕外，用滚轮缩小查看。

截图界面内移动鼠标，实时显示光标位置的 HEX／RGB。提示以透明背景的 16 DIP 文字与 18 DIP 色块固定在选区内底部，不拦截鼠标；字色依据底图明暗切换，窄选区简化为 HEX 和 C 提示。框选前后、选区内外以及标注模式均可查看。默认复制 #RRGGBB；按一次 Shift 在 HEX / RGB 之间切换，提示首项显示当前格式，按 C 复制并保留截图界面；取色工具也支持单击复制当前格式。截图操作层及工具栏焦点不启用输入法，C 按物理按键识别；文字标注框仍支持中文输入，其中的 C 用于输入文字。取色读取进入截图时冻结的原始屏幕像素，不包含标注或工具栏，也不会持续重新抓取桌面；所取颜色可用于后续标注；复制色值前提交正在绘制的笔画，保留该笔画的原色。

工具栏组织参考 Flameshot；图标使用 Lucide，完整许可见 [Lucide.txt](licenses/Lucide.txt)。
