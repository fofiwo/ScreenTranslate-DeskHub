# 设备连接、同步反馈与文件发送

剪贴板窗口常驻显示在线设备数量，以及剪贴板、资料库和文件的分项结果。点击设备状态打开设备列表，点击“记录”查看同步历史，“发送文件”用于选择文件或文件夹及接收方。等待、进度、完成、拒绝、取消、失败与中断均有明确反馈，记录保存最近 100 条，重启后仍可查看。重启前尚未完成的任务会标记为中断。

## 多台设备

“设备与同步”支持最多 16 个独立连接。每台设备显示名称、地址、连接或重连状态、剪贴板与资料库开关、最近连接时间及同步结果。选择设备后可以进入设置、重试、断开或忘记设备。

多台设备可同时在线。剪贴板同步按设备开关生效，可经中间电脑转发到其他已开启设备；同一条复制消息保留原编号，避免环形连接循环覆盖。资料库通过现有的版本向量合并，冲突保留副本。资料库开关涉及模型 API Key，应由用户逐台确认。

接收的新剪贴板记录在卡片正文下方显示“来自 设备名”，完整预览顶部也显示来源；可按设备名搜索。文本和图片均保留来源，中间电脑转发时继续携带原始设备名。设备名来自已配对设备提供的消息信息，不代表独立验证了原始电脑身份。旧记录没有保存设备名时仍显示“局域网”，不会猜测来源；旧版中继没有保留来源时，只能显示最近一跳的设备。

资料库每轮结束后约 3 秒检查一次文件状态，同一进程的设备连接共享加密状态读取缓存；文件变化时重读，另每 30 秒完整重读兜底。内容未变化时跳过整库导出和序列化。首次连接、重连及暂停后恢复发送完整快照；连接期间按对方已确认的记录版本发送新增、修改、删除标记及并发分支，拒收或保存失败不会推进发送进度。合并、冲突保留和整库大小限制沿用原规则；本机偏好变化不会作为资料变化发送。传输格式保持兼容现有版本。

## 自动重连

首次配对时可勾选“记住此设备，启动后自动重连”。信任文件整体使用 Windows 当前账户的 DPAPI 加密，包含恢复认证所需的证书和配对信息；不写明文凭据，不同步此文件到对方。重启后恢复原连接角色与端口，连接方先尝试保存的地址，失败后尝试设备主机名解析出的局域网地址，仍以保存的证书指纹认证。

连接失败时显示原因并按 2、4、8、16、30 秒的间隔重试。手动断开会暂停该设备的自动重连；“重试连接”恢复重连。“忘记设备”清除本机信任并断开，之后需要重新配对。地址无法解析、端口持续占用、对方未启动或信任失效时，会保留失败反馈，不假报已连接。

重连成功后资料库继续自动合并；剪贴板只同步新复制内容，不补发离线复制记录；中断的文件任务需用户重新选择接收方发送。

## 文件与文件夹

可把文件或文件夹拖入剪贴板窗口，点击“发送文件”，或使用文件历史记录上的发送按钮。选择接收方后发送；其他在线设备不接收本批文件。接收方先确认并选择保存目录，随后才传输文件内容。每批保存到所选目录中的独立文件夹，保留目录结构和空文件夹，同名批次自动改名，保留已有文件。

每批最多 100 个所选项目、10000 个文件与目录、64 GB。准备阶段需要本机临时磁盘空间，接收方需要容纳传输包和解包结果的空间。符号链接、目录联接、危险文件名、越界路径和重复路径会被拒绝。失败时清理本批临时内容；完成后可从记录打开接收目录，发送失败或拒绝后可重新选择接收方发送。

新功能需双方使用支持接收确认和信任恢复的版本。旧版直接推送不能绕过新版接收确认，会被拒绝并提示更新。同步记录不保存剪贴板正文、资料库内容、API Key 或配对码；文件记录会保存用户选择的路径，供重试与打开接收目录使用。

## 验证范围

实现以临时目录、合成内容、独立传输节点及 WPF 渲染检查验证。源代码测试和构建通过不代表日常安装版本已更新；真实多台电脑的应用升级、物理拖拽、系统文件夹选择器及跨电脑重启验收需要在安装新版本后执行。
