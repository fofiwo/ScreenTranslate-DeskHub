# 桌面视觉语言调整 · 2026-11-11

## 问题与参考

改动前的窗口、侧栏、内容区同为白色，主要依靠细线区分；设置页、Tab、资料库列表和弹窗采用不同分隔方式。问题在于层级缺少一致性，而非线条本身需要加粗。

本轮选择 Microsoft Fluent / Windows 11 作为主要参考，原因是产品本身为原生 Windows 工具，用户频繁使用键盘、窗口拖动、缩放、托盘与短时浮窗。借鉴其信息层级和交互表达，保留现有 WPF 技术栈、业务路径和品牌蓝。

官方资料（2026-11-11 经本机代理读取）：

- [Elevation in Windows](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/layering)：窗口底层容纳导航，内容层聚焦任务；阴影表达浮层关系，避免装饰性滥用。
- [Geometry in Windows](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/geometry)：控件、容器和弹层采用有规律的圆角、嵌套与间隔。
- [Design Windows apps](https://learn.microsoft.com/en-us/windows/apps/design/)：清晰、可访问、一致，兼顾导航、字体、色彩和材料。

这是基于 Fluent 原则的 WPF 实现，不是 WinUI 组件替换，也没有模拟 Mica/Acrylic 材质。

## 落地规则与范围

| 对象 | 调整 | 保留的边界 |
| --- | --- | --- |
| 主窗口、侧栏 | 浅灰窗口底 #F3F5F9 + 白色圆角内容层，移除侧栏接缝线 | 标题栏、侧栏折叠、快捷唤出与导航事件 |
| 导航、模式、Tab | 淡蓝选中底；主导航有 3 DIP 标记；取消整条下划线 | Checked / SelectionChanged、键盘焦点与禁用态 |
| 首页、截图工具 | 按用户最终确认使用原色亮橙黄 #FFBE24，辅助任务用有留白的浅色块 | 开始框选、截图、贴图、取色、提示与服务选择 |
| OCR、AI、网络代理 | 用浅色分组底与 20 DIP 留白替代横线和套框 | 原有命名字段、保存/取消/测试、密钥输入控件 |
| 持续翻译 | 分组底、统一内边距与圆角，内组不描边 | 捕获方式、窗口选择、外观、会话动作 |
| 资料库 | 列表取消逐行分割线；浅色列表和正文预览 | 搜索、虚拟化、复制、编辑、拖动排序、选中文字 |
| 消息弹窗 | 白色正文、灰色操作区、标题图形标记；正文 14 / 行高 24 | 默认按钮、Esc/关闭取消、安全确认和复制 |
| 发送、设备、同步记录 | 灰标题区、白色正文、无描边列表 | 接收方、待发送项目、状态、重试与取消 |
| 同步引导和配对 | 白色内容与底部操作区；复用共享分组样式 | 原有配对、权限、信任与同步规则 |

输入控件和次按钮仍保留必要边界，焦点、悬停、按下和选中反馈继续保留；没有为了消除所有线条而降低可操作性。业务代码、数据格式、网络与同步协议不属于本轮改动。

## 验证与证据

使用独立 `VisualRefresh` 构建配置，沿用已有自动化测试和合成资料，不替换日常 app，不运行生产 App.OnStartup，不读取个人配置或凭据。

- 改动前 `SCREEN_TRANSLATE_LAYOUT_ONLY=1` 界面回归通过并保留截图。
- 改动后的布局回归通过：设置、快捷键、资料库、弹窗，以及 100%、125%、150%、200% DPI 离屏渲染。
- 最终细节调整后的完整 WPF 界面综合场景通过：1 项测试、0 失败、0 跳过，耗时 1 分 9 秒；该测试包含多个页面和交互断言，不是全仓测试。
- 相关核心测试选取 `ShellWindowMarkupTests`、`ShellQuickToolLayoutTests`、`ScreenTranslateTests`，22 项通过，无跳过。
- 18 个改动 XAML 的业务控件名称和事件绑定逐项对比编辑前快照；仅删除装饰用 Tab 下划线，保留原有业务名称和事件处理器。
- 新表面上的辅助文字对比度 5.32:1，导航蓝字 8.45:1；最终亮橙黄任务区标题/说明为 9.17:1 / 5.99:1。这不是全应用无障碍审计。
- 构建与界面测试已包含 XAML 编译；`git diff --check` 通过。

截图与前后对照保存在 `artifacts/visual-refresh-20261111/`。截图来自真实 WPF 控件树，展示测试文字；不是网页重绘或产品运行数据。
