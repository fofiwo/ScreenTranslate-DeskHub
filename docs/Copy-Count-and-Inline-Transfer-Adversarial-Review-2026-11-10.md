# 复制次数同步与 Tab 内文件发送：对抗性复核

2026-11-10。源码与本机隔离回归结论：**PASS_WITH_RISKS**。本次确认的产品问题已修复；日常安装版本和真实双机验收仍为 **未验证**。

## 范围与基线

复核本会话新增的复制次数同步、Tab 内发送、文件与文件夹拖入，以及直接涉及的持久化、增量同步、接收方选择和取消流程。基线为本会话上一轮实现；没有重置工作区或覆盖日常 app。

工作区还有并行任务的首页恢复、刷新性能及相关测试改动，均保留，不归入本轮修复。使用 CodeGraph 和当前 diff 检查直接调用方、资料库刷新消费者与传输边界，按 delivery-review 的实施收尾模式处理确认问题。测试只使用临时目录、虚构内容和合成凭据；未读取个人资料、真实 API Key、配对密钥或 `.env*`。

## 确认发现与修复

| 发现 | 触发及实际后果 | 修复与验证 |
| --- | --- | --- |
| P2：旧计数的设备归属只在导出副本中生成，没有持久化；换设备后可能重复累计 | 旧数据为 7 次，设备标记失效后复制一次，再合并原设备；预期 8，实际 15。另一个回归确认同步后磁盘上的计数分量仍为空 | 首次同步保存旧计数归属；更换设备 ID 前先把历史次数归入原设备，新复制才归入新设备。两个新增用例在修复前均失败，修复后通过 |
| P1：接收方断线后自动改选其他在线设备 | 两个真实回环连接中选中 A，A 断开后下拉框自动变成 B，“发送”仍可用，可能把下一批发到非预期设备 | 独立保留原选择 ID；断开后取消当前选择并禁用发送，要求重新选择。验证跨 Tab 再次刷新也不自动改选，B 没有收到文件。修复前用例实际选中 backup-fixture 而失败，修复后通过 |
| P2：Tab 内发送缺少直接取消入口，发送时“记录”也被忙碌标志拦住 | 等待接收或发送大批次时，Tab 内不能直接取消；“记录”按钮点击无效。由完整事件路径与旧 diff 确认 | 添加“取消传输”，绑定本批实际设备；允许发送期间打开记录，关闭记录后保留正确忙碌状态。实际回环等待接收时打开记录、取消、保持源列表且无额外接收批次，均通过 |

另修正两项测试证据问题：

- 剪贴板测试以 `!IsBusy` 作为全部落盘结束的条件，但历史写盘在之后异步进行；临时目录清理曾撞上 `.clip.tmp`。现等待实际复制时间提交后再清理，不增加固定等待、不吞清理异常。
- 最小窗口截图辅助函数只按给定尺寸输出图像，不会调整窗口；直接传入 460×400 会裁掉仍为 560×700 的窗口。现先真正调整窗口、布局并检查取消按钮边界，再渲染，随后恢复窗口尺寸。

## 全部已知剩余问题与未验证项

1. **日常运行版本未更新**：没有替换 app、重启用户程序、发布安装包、提交或推送。本报告不证明当前日常窗口已经使用新代码。
2. **真实双机未验证**：回环连接证明本机 TLS/传输/同步路径；没有证明两台物理 Windows 电脑、跨机器 DPAPI、实际防火墙、IP 变化、休眠唤醒或重启后的综合行为。
3. **物理 UI 未验证**：拖拽测试使用实际 WPF 事件路由和虚构文件，没有做 Explorer 物理拖拽、原生文件/文件夹选择器实操、管理员与普通权限进程之间拖拽、全部混合 DPI/多显示器、辅助技术或长时间操作。渲染图是离屏控件树，不是桌面截图。
4. **旧版计数同步有边界**：旧版仍不发送本机次数，需两端更新；旧版往返不会清空新版已有分量，但不能凭此声称旧版新复制次数也已同步。迁移保留现有本机数值，不能恢复已经丢失的历史复制；在同步元数据产生前就被复制成多个独立资料库的相同历史数值，没有可用于判断共同来源的证据。
5. **数值与资源边界**：每个提示词最多保留 128 个设备分量，总数上限为 long.MaxValue；越界被拒绝且不部分写入。未做长期反复换机逼近分量上限、实际 64 GB 文件、10000 项的真实满载、磁盘满、ACL 拒绝、断电、强杀或文件系统故障注入。取消中途传输可能关闭连接，需重连后重试，未增加断点续传。
6. **正常退出和异常中断并不等价**：已有回归覆盖正常退出等待复制计数保存；剪贴板已成功但落盘前发生崩溃、强杀或断电，仍可能漏记，不提供剪贴板与文件系统之间的原子事务。
7. **剪贴板偶发失败尚无根因结论**：上一轮扩展资料库回归出现过 `Clipboard busy`。本轮一次 Release 扩展回归通过，并取得上述真实剪贴板证据；未改剪贴板实现，不能把一次通过表述为已消除所有外部占用或长期争用问题。另一次本轮测试失败为临时目录清理早于异步写盘，已按可观察提交条件修正。
8. **17 项未执行**：为真实 OCR/模型加载、图像及识别相关条件用例，完整名称见 `skipped-tests.json`；不算通过。本轮没有替代真实模型、翻译 Provider 或全产品截图/OCR 验收。编译仍有其他模块的 CA1416、空值与测试等待分析警告，未扩展修改。
9. **并行改动的范围边界**：保留其他任务正在进行的首页、刷新、截图/剪贴板及其测试现场。全量测试是执行时组合源码的结果；本轮不对那些功能另作完整对抗性验收。源码清单与被测程序集散列见证据目录。

本轮确认的三类产品问题均已处理；以上边界和未验证项仍保留，不代表全系统不存在未知缺陷。
