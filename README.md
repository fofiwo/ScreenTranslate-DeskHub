# 🧰 ScreenTranslate DeskHub

**一款把截图、屏幕翻译、文字提取、剪贴板历史和常用 AI 资料放在一起的 Windows 桌面工具。**

图片里的字复制不出来？外语界面看不懂？刚复制的内容被下一次复制覆盖了？两台电脑之间总要借助聊天软件传东西？DeskHub 为这些日常小麻烦提供快捷入口，用到哪项就打开哪项。

📷 截图标注 · 📌 桌面贴图 · 🎨 屏幕取色 · 🌐 屏幕翻译 · 🔤 图片提取文字 · 📋 剪贴板历史 · 📝 提示词库 · 🔗 多电脑同步

**[⬇️ 下载 Windows 安装包](https://github.com/fofiwo/ScreenTranslate-DeskHub/releases/latest)** · [🚀 安装与数据恢复](docs/ScreenTranslate-Install.md) · [🔗 设备连接与文件发送](docs/ScreenTranslate-Lan-Sync.md)

> 🪟 支持 Windows 10 / 11，64 位（x64）。下载后运行 `ScreenTranslate-win-Setup.exe`，无需编程、Docker 或 Python。部分持续翻译能力有额外系统要求，见下文。

## ✨ 具体能做什么？

### 📷 截图、标注与取色：把问题说清楚

按 **`Ctrl+Alt+Q`**，拖动鼠标框选需要的画面。选区可以移动、调整大小，还能添加矩形、箭头、画笔、文字和马赛克，支持撤销、重做以及颜色、粗细调整。

- **发给别人看：** 标注完成后双击选区，或按 `Enter` / `Ctrl+C` 复制，再到聊天或文档中粘贴。
- **留下来对照：** 在截图界面按 `Ctrl+P`，把这张图贴在桌面上；也可按 `Ctrl+Alt+I` 贴出剪贴板里的图片。支持多张并存、拖动和滚轮缩放，双击贴图恢复原始大小。
- **取一个颜色：** 截图界面会显示鼠标位置的色值，按 `C` 复制；按 `Shift` 切换 HEX / RGB 格式，方便填入设计工具。

独立截图不启动翻译服务、不上传图片，也不自动保存文件。更多操作见 [📖 截图工具说明](docs/Screenshot.md)。

### 🌐 屏幕翻译：看懂那些无法选中的外语

先选择原文语言、目标语言和翻译服务，再按 **`Ctrl+Alt+A`** 框选内容。软件识别屏幕上的文字，将译文显示在原文位置；可以隐藏译文看原图，也可以复制识别文字和翻译结果。

遇到不断变化的内容，可在主窗口选择 **“持续翻译”**，选定目标窗口或屏幕区域。文字变化后会更新结果，支持暂停和继续。适合尝试阅读视频中已有的外语字幕、游戏对话或漫画文字；实际效果受字体、画面清晰度、捕获权限和翻译服务影响。

> 💡 这是识别画面中已有文字的翻译，不是听声音生成字幕。窗口持续捕获需要 Windows 10 1903 或更新版本；桌面持续捕获需要 Windows 11 24H2 的相关系统能力。受保护视频、独占全屏游戏等画面可能无法捕获。

### 🔤 提取文字：少打一遍图片里的字

**OCR 就是“把图片里的字变成可以复制的文字”。** 按 **`Ctrl+Alt+D`** 框选，识别成功后自动复制，再到需要的位置粘贴。这个入口只提取文字，不请求翻译。

默认尽量保留换行、段落和表格文本的行列关系，也可关闭“保留原文格式”来整理排版断行。它不还原原文件的字体、颜色或完整文档版式；模糊、小字和复杂排版仍需检查识别结果。

内置本地文字识别，也可自行配置 HTTP OCR 或百度 OCR。选择本地识别时，图片在本机处理；选择在线 OCR 时，框选图片会发送给所选服务。

### 📋 剪贴板历史：找回前面复制过的内容

软件运行且开启记录时，会保存新复制的内容。按 **`Ctrl+Alt+V`** 打开历史窗口，按关键词搜索，或按文本、图片、链接、文件等类别筛选；常用记录可以置顶。

默认点击条目或按 `Enter` 会复制并尝试粘贴到原输入位置。也可以关闭“点击后自动粘贴”，只复制后自己粘贴。软件有独立历史，不要求先开启 Windows 剪贴板历史。

> 💡 文件记录保存的是原文件的路径，不能代替文件备份。软件未运行或暂停记录期间的复制不会被记录；历史不会自动清理，长期使用需要留意磁盘占用。

### 📝 提示词库：常用的 AI 指令随手取用

“提示词”就是你交给 AI 的指令，例如“把下面这段话改成更礼貌的客服回复”。把常用指令存下来，就不用每次重新编写或翻聊天记录。

按 **`Ctrl+Alt+P`** 打开资料库，可以新建、编辑、搜索并用标签筛选，点击提示词即可复制。可选的 AI 整理能辅助生成标题、描述和标签，需要另行配置服务，使用时会发送提示词内容并可能消耗服务额度。

### 🗂️ 模型库：集中保存 AI 连接资料

如果你经常使用不同 AI 平台，可以在资料库的 **“模型资料”** 页面保存服务地址、API Key（访问服务用的密钥）、模型名称和备注，需要时分别复制；支持获取服务提供的模型列表和拖动排序。

这里用于管理连接资料，保存资料不会自动购买服务，也不会自动应用到翻译设置。不使用自定义 AI 服务的用户可以跳过。

### 🔗 多电脑协作：少一次中转和重复整理

两台或多台电脑连接到同一可信局域网，例如同一路由器下的家庭或办公室网络，并运行兼容版本后，从 **“设备与同步”** 完成地址、配对码和设备确认，即可选择同步内容。

| 内容 | 连接后会发生什么 |
| --- | --- |
| 📋 剪贴板 | 新复制的文本、图片可同步到其他已开启同步的电脑；不补传离线记录或整份历史 |
| 📝 提示词与模型资料 | 首次合并两端资料，随后同步新增、修改和删除；同时修改会保留冲突副本 |
| 📁 文件与文件夹 | 手动选择或拖入剪贴板窗口，再选择接收电脑；对方确认并选择保存目录后才传输 |
| 🔄 设备连接 | 配对时可勾选“记住此设备，启动后自动重连”；手动断开后会暂停自动重连 |

可以分别控制每台设备的剪贴板和资料库同步，并查看传输进度、成功或失败记录。中断的文件任务需要重新发送。

> 🔐 **模型资料同步包含 API Key，只应与自己的可信设备配对。** 同步使用加密连接，敏感字段在接收电脑上由 Windows 当前用户保护。局域网同步不是互联网云盘，也不等于跨电脑备份。

配对、重连与文件发送详情见 [🔗 设备同步说明](docs/ScreenTranslate-Lan-Sync.md)。

## 🚀 第一次使用，从这里开始

1. **⬇️ 下载并安装**：打开 [最新版本页面](https://github.com/fofiwo/ScreenTranslate-DeskHub/releases/latest)，下载 `ScreenTranslate-win-Setup.exe` 并运行；普通使用无需下载源码或执行命令。
2. **📷 先试一次截图**：启动后按 `Ctrl+Alt+Q`，框选、画一个箭头，再按 `Enter` 复制，粘贴到聊天或文档中。
3. **🎯 按需求选择功能**：需要翻译，先选择语言和服务；只想复制图片里的字，用“提取文字”；常用内容放到剪贴板历史或提示词库。
4. **💻 有多台电脑再配对**：首次启动的同步询问可以跳过，以后从“设备与同步”进入；不影响单机功能。

软件可以留在系统托盘运行，需要时用快捷键唤出。快捷键可在设置中修改；若与其他软件冲突，请换成自己习惯的组合。

## 💬 安装前，你可能还想知道

### 💰 软件收费吗？需要联网吗？

软件按 MIT 许可证开源。截图、标注、贴图、取色、剪贴板历史和资料库本地管理不需要付费 AI 服务；本地 OCR 的识别过程在本机进行，所需模型资源需先准备好。

**在线翻译、在线 OCR、AI 整理以及自定义模型服务的费用和额度由对应服务商决定**，软件不附送这些服务的付费额度。文字识别和翻译是两个步骤：本地识别并不代表翻译也离线。使用在线翻译时，待翻译文字会发送给所选服务；如需本地模型翻译，需自行准备兼容服务。局域网同步需要设备彼此可连接，不依赖互联网云盘。

### 🔒 我的资料放在哪里？

安装版的个人数据保存在安装根目录的 `data`，另在 `%UserProfile%/.ScreenTranslate/recovery` 保留重装恢复副本。公开源码和安装包不包含开发电脑的剪贴板、资料库、密钥或用户设置。

剪贴板可能记录你主动复制的敏感内容，可以暂停记录或手动删除。恢复副本不能代替独立备份；部分数据的保护绑定当前 Windows 用户，直接复制数据目录到另一台电脑不等于完成迁移。详见 [📂 安装与恢复说明](docs/ScreenTranslate-Install.md)。

### 🔄 以后怎么更新？

安装版启动后及运行期间每 30 分钟检查新版，也可从“关于与更新”或托盘主动检查。发现新版后点击“立即更新”，软件会下载、校验、安装并重启，保留个人数据；支持直接跨版本更新。

更新窗口可“刷新版本”，网络失败可重试。即使本机自行打包的版本号更高，也可选择切换到 GitHub 最新正式版；版本号相同则不重复安装。早期未启用在线更新的版本需先手动安装一次本仓库的安装版。不要删除数据目录来更新软件。

### 🌐 下载或在线服务连接失败怎么办？

可在 **“设置 → 通用与诊断 → 网络代理”** 填写 HTTP、HTTPS 或 SOCKS5 代理地址，启用后勾选需要使用代理的功能，再点“保存并应用”。可分别控制应用更新、翻译、词典、语音、在线 OCR、模型下载、资料库联网和诊断上传。

未启用或未勾选时使用系统默认网络；已启用代理失败时不自动改为直连。本机接口和局域网同步不经过此代理，外部浏览器与 Windows 管理的下载使用各自设置。代理地址不支持内嵌账号密码。

### 🪟 有哪些使用限制？

当前面向 Windows 10 / 11 x64；识别和翻译质量依赖画面及所选服务，重要内容请核对原文。持续捕获对系统版本和目标程序有要求，不能保证所有游戏、受保护画面或显示器组合都可用。

安装包目前未作 Windows 代码签名，可能显示未知发布者或 SmartScreen 提示，请核对下载来源。README 描述当前源码能力，具体安装包以其版本说明为准；真实多电脑、各类输入法和多屏环境仍需按实际设备验证。

## 🛠️ 开发与发布

<details>
<summary>面向开发者：源码、测试、打包与发布方式（普通用户可跳过）</summary>

源码位于 `src/`，解决方案为 `src/OverTranslate.slnx`。开发使用 .NET 8 SDK 和 Windows x64 环境；使用安装版不需要 SDK。

```powershell
dotnet test src/OverTranslate.Tests -c Release
dotnet test src/ScreenTranslate.UiTests -c Release
dotnet tool install vpk --version 1.2.0 --tool-path .tools/velopack
./build-screen-translate-installer.ps1 -Version 0.3.0
```

示例中的版本号仅用于说明打包参数，正式发布应使用新的版本号。

向公开仓库 `main` 推送涉及 `src/**`、安装包构建脚本或发布工作流的改动后，GitHub Actions 自动测试、构建干净安装包，发布 `0.3.<run_number + 1>` 稳定版及 `releases.win.json` 更新源。纯 README 改动不触发该发布工作流。测试或构建失败不发布，完整资产上传后才公开版本。

客户端读取 Release 的静态更新清单，避免匿名 API 限流；下载锁定已提示的版本。发布凭证使用 Actions 内置权限，客户端不需要 GitHub Token。

原开发目录使用 `./publish-deskhub.ps1 -Message '本次更新说明'` 导出清理后的源码并推送独立公开仓库，`README.DeskHub.md` 会成为公开仓库的 `README.md`。普通公开仓库克隆直接提交、推送即可，无需再次导出。

公开仓库只包含清理后的源码快照和后续提交，不包含原工作区历史、个人数据或本机 Agent 配置。安装包不应携带个人资料或本机路径绑定。

</details>
